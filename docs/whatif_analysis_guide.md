# What-if 分析 結果の読み方ガイド

`notebooks/04_predict_analysis.ipynb` の What-if 分析セクション（基本版 + Step 1〜3）で出力される結果を、**非データサイエンティストも含めたチーム全員が同じ理解で読める**ようにするためのガイド。

- 対象ファイル: [notebooks/04_predict_analysis.ipynb](../notebooks/04_predict_analysis.ipynb)
- 関連: [evaluation_metrics.md](evaluation_metrics.md) / [bi_tool_phases.md](bi_tool_phases.md)

---

## 1. このドキュメントの位置づけ

| 想定読者 | 何を得てほしいか |
|---|---|
| データサイエンス担当 | 出力の数値が何を意味するかの正確な定義 |
| プロダクト/業務担当 | 顧客向け説明・社内意思決定での使い方、誤解の回避 |
| マネジメント | 「このモデルは何を説明できて、何を説明できないか」の境界 |

What-if 分析は強力だが、**「相関の可視化」を「因果」と誤読されやすい**ため、用語と注意点を共有しておくのが目的。

---

## 2. What-if 分析とは

### 2.1 ひと言で

> 「**もし**この物件の○○を△△に変えたら、**モデルの予測**はどう動くか？」

これだけ。重要なのは「**もし**」「**モデルの予測**」を必ず文中に含めること。

### 2.2 SHAP との違い

| 観点 | SHAP | What-if |
|---|---|---|
| 答える問い | この予測値は各特徴量がどう積み上げたか | 入力を変えたらモデルの予測はどう動くか |
| 結果の形 | 寄与の分解（静的） | 変更レシピと予測差（動的） |
| 業務との接続 | 「説明はできるが次の行動が見えにくい」 | 「次にできること（改装する／拡張する）が直接見える」 |
| 誤読リスク | 「○○が原因で価格が上がる」と読まれがち | 「**もし**○○なら」のフレーミングで誤読が軽減 |

SHAP と What-if は補完関係。SHAP で「全体傾向」、What-if で「個別物件の行動提案」と使い分けると説明力が増す。

---

## 3. 因果関係との取扱い（最重要）

### 3.1 What-if は因果ではない

What-if が示すのは **「モデルがどう反応するか」** であって、現実世界での因果関係ではない。

具体例:

| What-if 出力 | 正しい解釈 | 誤った解釈 |
|---|---|---|
| 「改装すると予測 +8%」 | モデルは『改装フラグ=1』の物件を平均的に 8% 高く予測する | 改装すれば 8% 高く売れる |
| 「築年数 0 にすると +25%」 | モデルは新築物件を平均的に 25% 高く予測する | 築古でも見せ方を新築風にすれば 25% 上がる |

「モデル予測 ≠ 市場価格」「相関 ≠ 因果」を常に意識する。

### 3.2 説明する時の言い換え集

| 避ける表現 | 推奨する表現 |
|---|---|
| 「面積が広い**から**高い」 | 「モデルは面積を**手がかり**として高く予測した」 |
| 「リフォームすれば 8% 上がる」 | 「**モデル予測上**では、改装フラグが立つと 8% 高くなる」 |
| 「築古は価格が下がる」 | 「築古物件をモデルは**平均的に**低く予測している」 |
| 「○○が価格を押し上げた」 | 「○○の値を見て、モデルは予測を押し上げた」 |

文末に「※モデル予測上の話であり、実取引を保証するものではありません」と添える運用も有効。

## 4. 出力の読み方（基本版）

ノートブックの SHAP セクション直後にある「## What-if 分析（Counterfactual）」の出力。

### 4.1 対象物件の表示

```
対象物件のモデル予測: 57,023,241 円

対象物件の主要特徴量:
  種類            中古マンション等
  面積（㎡）       75
  築年数           2
  市区町村コード    13213
  最寄駅：名称     久米川
  ...
```

→ どの物件を分析しているかを必ず確認する。`X_sample.iloc[[0]]` の N を変えれば別の物件を題材にできる。

### 4.2 What-if 結果テーブル

| 列名 | 意味 |
|---|---|
| 特徴量 | 変えた特徴量 |
| 元の値 | この物件の元の値 |
| 変更後 | 試した値 |
| **予測差 (%)** | 元予測との比率差。「**もし**変更後にしたらモデル予測がこれだけ動く」 |
| 予測差 (円) | 同じく円スケール |
| 予測価格 (円) | 変更後のモデル予測値 |

> 「予測差 (%)」が **正の値** = その変更でモデル予測が**上がる**。**負の値** = 下がる。

### 4.3 グリッド棒グラフ

各特徴量について「変更後の値」を横軸、「予測差 (%)」を縦軸にした棒グラフを 2×3 で並べたもの。

| 色 | 意味 |
|---|---|
| 青 | 試した値 |
| 赤 | この物件の**元の値**（基準位置） |

読み方:
- 赤いバーから離れるほど、その特徴量を大きく動かしたことになる
- 縦軸 0 のラインから上下に伸びる量が「予測の動き」
- 曲線が**急峻** = その特徴量に敏感、**ゆるい** = 鈍感

## 5. Step 1（複数物件比較）の読み方

### 5.1 サンプル選定の表

```
サンプル: 15 件（価格帯 × 最大3件）
  index   band
   ...   ~2000万
   ...   ~2000万
   ...   2000万~5000万
   ...   ...
```

→ 各価格帯から最大 3 件、合計約 15 件を題材にしている。

### 5.2 価格帯別 集計表

```
=== 築年数を 0 にした時の予測差 (%) by 価格帯 ===
                  mean    min    max  count
price_band
~2000万          24.50  18.20  31.10      3
2000万~5000万    18.30  12.50  22.40      3
5000万~1億       16.10  10.20  19.80      3
1億~3億          12.40   8.50  16.20      3
3億~              9.20   5.10  13.00      3
```

| 列 | 読み方 |
|---|---|
| **mean** | 価格帯内の3物件で「築年数=0」が予測を平均何%上げたか |
| min/max | バラつきの幅。広いほど物件差が大きい |
| count | サンプル数（3 固定） |

### 5.3 価格帯別 感度の棒グラフ

3 種類の介入（築年数→0、面積→90、改装→1）の効きを価格帯別に並べたもの。

読み方のチェック項目:
- **どの介入が、どの価格帯で大きく効くか**
  - 例: 「築年数→0」が低額帯で +25%、高額帯で +10% → **低額帯は築年数感度が大きい**
- **介入間の優先順位**
  - 例: 低額帯は築年数 > 面積 > 改装、高額帯は面積 > 築年数 > 改装、など
- **予期しない方向**
  - 例: 「面積を 90 にしたら下がった」物件 → 元が 100㎡ で広い物件だった可能性

### 5.4 価格帯による感度差の解釈

価格帯ごとに反応が違う理由（モデル目線）:
- **低額帯**（~2000万）: 築古・狭小物件が多く、築年数を 0 にすると分布が大きく動く
- **高額帯**（3億~）: 立地ブランドが効くので、築年数を変えても予測がそこまで動かない

これは「現実の市場の話」ではなく「**モデルがこのデータから学んだ反応**」である点に注意。

## 6. Step 2（2 特徴量 heatmap）の読み方

### 6.1 単一 heatmap（築年数 × 面積）

各セルの色と数字 = その組合せでの予測差（%）。

| 領域 | 期待される傾向 |
|---|---|
| 左下（築新・小） | わずかにプラス〜マイナス（元から大きく離れない） |
| 右上（築古・大）か左上（築古・小） | 大きくマイナス（築古で予測が下がる） |
| 右下（築新・大） | 大きくプラス（築新で広いと予測が上がる） |

### 6.2 何を確認するか

1. **対角的なグラデーション**: 連続的に滑らかに色が変化しているか（不自然なジャンプがあれば派生未更新の影響）
2. **対称性の崩れ**: 「築年数を 10 → 0 に変える」と「築年数を 20 → 10 に変える」が同じ +5% にならない理由（非線形性）
3. **相互作用**: 「築新だと面積の効きが強い」「築古だと面積を増やしても効きが弱い」のような効きの方向の変化

### 6.3 複数ペアの heatmap

「築年数×面積」「駅徒歩×面積」「築年数×駅徒歩」の 3 枚を並べたもの。

業務に活かせる読み方:
- **どのペアが最も大きく予測を動かすか** = この物件への効きが最強の組合せ
- **どのペアでも変化が小さい場合** = この物件は予測値が固まっている（モデル的に確信度が高い）

### 6.4 派生未更新の影響

Step 2 までは `築年数^2` や `log_面積` を更新していないため、heatmap の数値には**多少の歪み**がある。

具体的なズレ方:
- 築年数を変えたつもりでも、モデルは `築年数^2` の側で古い値を見ている
- 「築年数 0 にしたら +25%」のような数字は **過小評価** されている可能性が高い

正確な数値が必要なら Step 3 の v2 を使う。

## 7. Step 3（派生特徴量更新）の読み方

### 7.1 動作確認の出力

```
=== 元の値 ===
  築年数        2
  築年数^2      4
  面積（㎡）   75
  log_面積    4.317

=== 派生更新後（築年数=5, 面積=100） ===
  築年数        5
  築年数^2     25     ← 5^2 = 25 になっているか
  面積（㎡）  100
  log_面積    4.605   ← log(100) ≈ 4.605 になっているか
```

→ 派生が正しく再計算されていれば成功。

### 7.2 v1 vs v2 比較テーブル

```
=== 築年数を振った時の予測差 (%) ===
        v1 (派生未更新)  v2 (派生更新)
築年数
0                12.5              25.3
10                4.2               8.7
20                0.0               0.0
30               -3.5              -6.2
40               -7.1             -12.4
```

| 観察 | 意味 |
|---|---|
| v2 の方が振れ幅が大きい | 派生も同時に動くため、モデルの反応がより素直に出ている |
| v1 と v2 で符号が違う | 派生によって**逆向きの効き**が打ち消されていた |
| ほぼ同じ | この物件はモデルが派生特徴量をあまり使っていない |

### 7.3 v1/v2/差分 の 3 連 heatmap

| パネル | 意味 |
|---|---|
| 左: v1 (派生未更新) | Step 2 の heatmap と同じ |
| 中: v2 (派生更新) | 正しい heatmap |
| 右: 差分 (v2 - v1) | 派生更新で何 % 修正されたか |

差分パネルの読み方:
- **絶対値が大きいセル** = そこは派生未更新の影響を強く受けていた
- **対角線状に大きい** = 生特徴量と派生特徴量が両方とも変わるケースで影響大
- **ほぼ0** = この物件・この組合せでは派生の影響が小さい

### 7.4 「差分の絶対値の最大」の値

```
差分の絶対値の最大: 3.5 %
```

| 値 | 解釈 |
|---|---|
| < 1% | 派生の影響は無視できる。Step 1/2 の結果もほぼ正確 |
| 1〜5% | 一般的な範囲。重要な意思決定には v2 を使う |
| > 5% | 派生の影響が大きい。Step 1/2 の数値は鵜呑みにせず v2 で再計算推奨 |

## 8. 結果を業務報告書に書く時のテンプレート

### 物件1件の説明（顧客向け）

```
物件: 〇〇区〇〇 75㎡ 築2年 中古マンション
モデル予測価格: 5,702 万円（実取引: 5,400 万円、誤差 +5.6%）

【もしこの物件を…】
- リフォーム済にすると → モデル予測 +8%（6,158 万円相当）
- 築年数 10 年と仮定すると → モデル予測 -12%（5,018 万円相当）
- 面積 90㎡ なら → モデル予測 +15%（6,557 万円相当）

※ いずれもモデルの内部反応であり、実際の市場価格を保証するものではありません。
```

### 価格帯別の傾向（社内レポート）

```
What-if 感度の価格帯別傾向（n=3/帯）

低額帯（〜2000万）  : 築年数感度 高（築年数→0 で平均 +24.5%）
中央帯（2000万〜3億）: バランス型（築年数 +18% / 面積 +12% / 改装 +5%）
高額帯（3億〜）     : 立地・面積感度 高、築年数感度 低（+9%）

含意:
- 低額帯では「築古をどう見せるか」が買い手提案の主軸になりそう
- 高額帯ではモデルの予測が固定的で、What-if での提案余地が小さい
```

## 9. よくある誤解と回避

| 誤解 | 正解 / 注意 |
|---|---|
| 「築年数を 0 と入力すれば古物件を新築扱いできる」 | モデルが学習した分布外を入れた時の予測は信用できない。新築域では大きく外す可能性 |
| 「リフォームすると 8% 上がる」 | モデルは「過去のリフォーム済物件は平均 8% 高かった」と言っているだけ。**個別物件で 8% 上がる保証は無い** |
| 「面積を変えれば変えるほど価格が上がる」 | 線形ではない。学習データの 5〜95 パーセンタイル外では崩れる |
| 「市区町村を変えれば一気に上がる」 | 場所は変えられない。What-if での提示自体を避ける（不変特徴量） |
| 「v2 の数値は完全に正確」 | v2 は v1 より正確だが、それでも「**モデル予測**の話」であって因果ではない |

## 11. クイックリファレンス

### 全体のチェックリスト
- [ ] 「もし」「モデル予測」を文中に必ず入れているか
- [ ] 不変特徴量（市区町村、緯度経度）を変えていないか
- [ ] 学習データの分布範囲内で値を振っているか
- [ ] 派生特徴量は更新されているか（v2 を使っているか）
- [ ] 注意書き（モデル予測上の話であり実取引を保証しない）を付けているか

### キーワード
- **Counterfactual / What-if**: 「もし入力を変えたら予測はどう動くか」
- **派生特徴量**: 生特徴量から計算される列（築年数^2、log_面積 等）。What-if では同時更新が必須
- **不変特徴量**: 物件で変えられない属性（市区町村、住所、緯度経度）。What-if では触らない
- **モデル予測上の話**: 「モデルの反応であって市場の因果ではない」を強調する言い回し
