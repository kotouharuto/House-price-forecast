## 高優先度（精度インパクト大・取得可能）

| カテゴリ | 具体的な特徴量 | データソース |
|---|---|---|
| **地価** | 地価公示・地価調査（最寄り地点との距離加重補間） | 国土交通省 不動産情報ライブラリ |
| **駅アクセス** | 最寄り駅までの徒歩分・乗換回数・都心主要駅（新宿/渋谷/東京）への所要時間 | GTFS-JP / 国土数値情報 鉄道データ |

| **施設近接性** | スーパー・コンビニ・病院・学校までの距離（POI） | OSM / 国土数値情報 |

## 融資判断・高精度AVMに向けた追加要素

| カテゴリ | 具体的な特徴量 | 理由 |
|---|---|---|
| **取引事例の時系列ラグ特徴** | 同建物・同路線の直近成約価格 | AVM精度の最大の差別化要因 |
| **建物スペック詳細** | 管理形態（自主/委託）・EV有無・オートロック・宅配ボックス | 賃料への直接影響 |
| **市場サイクル変数** | 日銀政策金利・長期金利（10年債）・J-REIT指数 | 融資判断には必須 |
| **再開発・都市計画情報** | 都市再生特別地区・開発許可区域 | 将来価値に直結 |

## 実装上の注意点

### 地価補間
公示地点はスパース（点データ）なため、単純な最近傍ではなく以下を推奨する。

- **IDW（逆距離加重）**: 実装が容易で安定した精度
- **Kriging**: より高精度だが実装コストが高い

### 駅所要時間
「最寄り駅名」だけでなく「都心アクセス時間」の方が説明力が高いケースが多い。
急行停車駅 vs 各停駅の差など、路線種別を加味すること。

### ハザードデータ
融資判断用途なら必須要件。以下の3種を独立した特徴量として入力する。

1. 洪水浸水想定区域（L1 / L2）
2. 土砂災害危険箇所
3. 液状化リスク
