## 1. 相関分析の要約

`取引価格（総額）` との相関が比較的大きい数値特徴量は以下。

| 特徴量 | 相関 |
|---|---:|
| `面積（㎡）` | +0.365 |
| `log_面積` | +0.308 |
| `山手線内側` | +0.222 |
| `has_L` | +0.219 |
| `建築年` | +0.206 |
| `築年数` | -0.206 |
| `築年数^2` | -0.190 |
| `中心地_距離` | -0.179 |
| `has_D` | +0.178 |
| `room_count` | +0.146 |
| `市区町村コード` | -0.143 |
| `最寄駅：距離（分）` | -0.075 |

読み取り:

- 価格には `面積` / `log_面積` が最も効いている。
- `築年数` は負、`建築年` は正で、築浅ほど高い傾向。
- `山手線内側` と `中心地_距離` から、都心性の影響が見える。
- `has_L`, `has_D`, `room_count` から、間取り・広さの情報も効いている。
- `最寄駅：距離（分）` 単独の相関は大きくないが、築年数・面積・都心性との交互作用は試す価値がある。

## 2. 強い相関がある既存特徴量

特徴量同士でかなり強く相関している組み合わせ:

| ペア | 相関 | 注意 |
|---|---:|---|
| `建築年` / `築年数` | -1.000 | 実質同じ情報。基本は `築年数` に寄せる |
| `建ぺい率（％）` / `log_建ぺい率` | +0.999 | 両方の必要性は要検証 |
| `容積率（％）` / `log_容積率` | +0.975 | 両方の必要性は要検証 |
| `建築年` / `築年数^2` | -0.968 | 築年系は冗長になりやすい |
| `築年数` / `築年数^2` | +0.968 | 非線形表現として残す価値はある |
| `面積（㎡）` / `log_面積` | +0.959 | LightGBMでは両方あってもよいが、重要度は確認 |
| `最寄駅：距離（分）` / `log_最寄駅：距離` | +0.917 | 距離系も冗長になりやすい |
| `最寄駅：経度` / `中心地_距離` | -0.897 | 都心距離・経度・市区町村コードは情報が重なる |

方針:

- 単独の変換特徴量を増やすより、**交互作用・フラグ・カテゴリ化** を優先する。
- `建築年` と `築年数` のような完全に近い重複は、モデル解釈時に注意する。
- LightGBM は多重共線性に比較的強いが、特徴量重要度や SHAP の解釈はぶれやすくなる。

## 3. 生成候補

### High

| 特徴量 | 計算式 | 狙い |
|---|---|---|
| `築年数_log_面積` | `築年数 * log_面積` | 築古かつ狭小の追加割引を表現 |
| `is_old_one_room` | `(築年数 >= 35) & (面積 <= 30) & (has_L == 0)` | 低額帯に多い築古ワンルームを識別 |
| `is_old_1K` | `(築年数 >= 35) & (面積 <= 40) & (has_L == 0) & (has_K == 1)` | 築古1Kの過大予測抑制 |
| `area_per_room` | `面積 / room_count.clip(lower=1)` | 1部屋あたり面積。極小ワンルーム識別 |
| `has_L_area` | `has_L * 面積` | LDK付き広め物件のプレミアムを表現 |

### Medium

| 特徴量 | 計算式 | 狙い |
|---|---|---|
| `築年数_鉄筋` | `築年数 * is_rc_src` | RC/SRC の築古劣化の出方を分離 |
| `築年数_鉄骨` | `築年数 * is_steel` | 鉄骨造の築年効果を分離 |
| `築年数_木造` | `築年数 * is_wood` | 木造の築年効果を分離 |
| `築年_駅距離` | `築年数 * 最寄駅：距離（分）` | 古くて駅遠い二重マイナスを表現 |
| `area_category` | `pd.cut(面積, [0,20,30,50,70,90,inf])` | 面積の非線形な価格差を段階的に表現 |
| `is_low_area` | `面積 <= 20` | 20㎡以下の極小物件を識別 |

### Low

| 特徴量 | 計算式 | 狙い |
|---|---|---|
| `山手線内側_log_面積` | `山手線内側 * log_面積` | 都心内側で広い物件のプレミアム |
| `中心地距離_log_面積` | `中心地_距離 * log_面積` | 都心距離による面積価値の違い |
| `駅距離_log_面積` | `最寄駅：距離（分） * log_面積` | 駅遠×広さの割引/補正 |

## 4. 実装時の注意

### 構造ダミーの typo

ノートブックで試し書きしている構造別特徴量は、`築年数_鉄骨` の式が誤っている。

```python
# NG
df["築年数_鉄骨"] = df["築年数"] * is_concreate.astype(int)

# OK
df["築年数_鉄骨"] = df["築年数"] * is_steel.astype(int)
```

`is_concreate` はスペルも `is_concrete` に直すとよい。

```python
is_concrete = df["建物の構造"].isin(["RC", "SRC", "SRC、RC"])
is_steel = df["建物の構造"].isin(["鉄骨造", "SRC、鉄骨造"])
is_wood = df["建物の構造"].eq("木造")
```

### カテゴリ特徴量

`area_category` のような離散化特徴量を追加する場合は、`categorize_features()` のカテゴリ列リストにも追加する。

### 評価観点

追加後は全体スコアだけでなく、以下を必ず確認する。

- 低額帯（~2000万）の Median APE / MAPE
- 中額帯（2000万~1億）の悪化有無
- 高額帯（1億以上）の悪化有無
- 特徴量重要度または SHAP で、追加特徴量が使われているか

## 5. 推奨する進め方

一度に全部入れると効いた特徴量が分からなくなるため、段階的に試す。

| Step | 内容 | 目的 |
|---|---|---|
| 1 | High の5特徴量だけ追加 | 主要交互作用の効果を見る |
| 2 | Step 1 + Medium の構造/駅距離/面積カテゴリ | 追加効果と副作用を見る |
| 3 | 効いたものだけ残す | 採用版の特徴量セットを整理 |

採用判断は、低額帯の改善だけでなく、中〜高額帯の悪化がないことを条件にする。
