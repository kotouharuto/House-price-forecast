## P0: 基盤 ✅

UIに依存しない集計ロジックを `src/visualization/` に集約し、薄いUI層から利用する土台を作る。

### スコープ（やること）
- 予測結果CSV（`outputs/test_predictions.csv`）の読み込みと必須列の検証
- `@st.cache_data` による読み込み・集計のキャッシュ
- 行政区単位・駅単位の集計テーブル生成（件数・予測/実測価格の平均と中央値・MAPE・Median APE）
- 入力CSVパスの設定切り替え（環境変数 `BI_PREDICTIONS_PATH`）
- 集計・フィルタ・KPIの純粋関数化とユニットテスト

### 対応要件
- **M-1**: データ読み込み・前処理

### 成果物
- `src/visualization/aggregate.py`（集計・フィルタ・KPI）
- `src/visualization/master.py`（市区町村コード↔名称マスタ）
- `src/visualization/format.py`（金額の「億・万」整形）
- `configs/tokyo_municipality_master.csv`
- `tests/test_aggregate.py` / `test_master.py` / `test_format.py`

### 改善作業で強化した点（P0-1〜P0-3）
- 残差の符号を `error_yen`（= 予測 − 実測）に一本化
- 必須列チェックをダッシュボードが参照する列まで拡張（読込時に不足を検知）
- 入力CSVパスを `BI_PREDICTIONS_PATH` で切り替え可能化

## P1: BIグラフ ⚠️

予測結果を非エンジニアでも直感的に把握できるグラフ群とフィルタを提供する。

### スコープ（やること）
- KPIサマリ（ヘッダ指標カード）
- Plotlyによる多面的なグラフ
- サイドバーフィルタ（全グラフ・KPIに連動）

### 含むグラフ（M-3）
| グラフ | 内容 | 状態 |
|---|---|---|
| 予測 vs 実測 散布図 | y=x基準線つき・色=APE | ✅ |
| 誤差分布ヒストグラム | APE / 残差(error_yen) を切替 | ✅ |
| 価格帯別 件数・精度 | 価格帯ごとの件数＋平均APE | ✅ |
| 行政区別 ランキング | 平均予測価格／平均APE（Top20） | ✅ |
| 駅別 ランキング | 同上（駅単位） | ✅ |
| 特徴量との関係 | 面積／築年数 × 予測価格（X軸selectbox・色=もう一方） | ✅ |

### フィルタ（M-6）
行政区（市区町村名で選択）・最寄駅（行政区に連動）・物件種類・価格帯（金額順）・面積レンジ・築年数レンジ・山手線内側。すべてグラフ・KPIに連動。✅

### KPIサマリ（M-2）
件数・R²(log)・MAE・RMSE・MAPE・Median APE をカード表示。✅

### 対応要件
- **M-2**（KPI）・**M-3**（グラフ）・**M-6**（フィルタ）

### 成果物
- `app/pages/1_BIダッシュボード.py`

### 改善作業で強化した点（P1）
- ランキング集計を `@st.cache_data` 付きヘルパー経由に変更（再計算を削減）
- 特徴量タブにX軸切り替え（面積／築年数）を追加

### 残課題（⚠️ 仕様 §3.3 ユーザビリティ未達）
| # | 不足点 | 根拠 | 優先 |
|---|---|---|---|
| 1 | グラフの金額が「円」生値表示（億・万併記はKPIのみ） | §3.3 金額は億・万併記 | 高 |
| 2 | 指標定義の説明がKPI下の参照テキストのみ（ツールチップ/リンク無し） | §3.3 定義にツールチップ | 中 |
| 3 | 散布図サンプリング（4000件上限）時の「サンプル表示中」明示が無い | UX（正確性） | 中 |
| 4 | ランキング棒グラフが単色（精度を色で直感表示していない） | §3.3 直感的なカラースケール | 低 |

> 緯度経度欠損件数の明示（M-1/§3.2）は地図表示が前提のため P2 で対応する。

## P2: 地図（駅単位）⬜

駅単位の集計値を地図上のマーカーで可視化し、クリックで詳細をポップアップ表示する。

### スコープ（やること）
- folium ＋ streamlit-folium を依存追加
- `最寄駅：緯度／経度` に集計マーカーを配置（サイズ／色＝予測価格 or APE）
- マーカークリックで件数・平均/中央 予測価格・実測価格・APE・代表的な種類/価格帯をポップアップ
- 緯度経度欠損行は地図から除外し、除外件数をUIに明示
- 表示指標の切替（平均予測価格／平均実測価格／平均APE）

### 対応要件
- **M-4(駅)**: 地図可視化（駅単位）
- **M-5(駅)**: クリック時ポップアップ

### 主なリスク
- `streamlit-folium` のクリックイベント仕様 → 冒頭でPoC（クリック→戻り値取得）

## P3: 地図（行政区）⬜

行政区（市区町村コード）単位でGeoJSONによるコロプレス（塗り分け）地図を描画する。

### スコープ（やること）
- 東京都市区町村のGeoJSON（国土数値情報 等）を調達
- `市区町村コード` をキーにGeoJSONと集計を結合してコロプレス描画
- 粒度トグル（駅／行政区）。初期表示は行政区単位をデフォルト
- 区画クリックで市区町村名・件数・予測/実測価格・APE・代表種類/価格帯をポップアップ

### 対応要件
- **M-4(区)**: 地図可視化（行政区単位）
- **M-5(区)**: クリック時ポップアップ

### 主なリスク
- GeoJSONの調達・コード整合 → 早期に確保し `市区町村コード` での結合を先に検証

## P4: 連携・仕上げ ⬜

地図とグラフを連携させ、分析体験を仕上げる。Nice-to-have を中心に対応。

### スコープ（やること）

- フィルタ後データ／集計結果のCSVダウンロード
- 残差の大きいワースト物件テーブル
- UI調整・全体仕上げ

### 対応要件
- **N-1**（地図⇄グラフ連携）・**N-2**（CSV出力）・**N-3**（ワースト物件テーブル）
